# ✨ 深圳6人吃喝玩乐小分队旅游指南 🐾

专属于 WaiKit, JingYi, Xavier, Tingfang, Gill & Dejun 6 人好友团的深圳旅游攻略交互网页！

## 🌟 核心功能
- **6人专属身份选择**：支持一键切换操作者（WaiKit、JingYi、Xavier、Tingfang、Gill、Dejun），投票实名显示头像与名字标签。
- **心愿投票箱**：实时投票统计，支持添加自定义想去的打卡点与美食。
- **可拖拽每日行程（SortableJS）**：5 天 4 夜行程卡片支持长按/鼠标拖拽调整顺序，支持为任意日期添加新行程或删除已有行程。
- **响应式与多巴胺配色 UI**：基于 Tailwind CSS、Google Fonts (ZCOOL KuaiLe/Nunito) 打造复古可爱波普卡片质感。
- **本地存储持久化**：投票记录与拖拽排序进度均自动保存在 LocalStorage。

## 🚀 本地运行
```bash
node server.js
```
访问：`http://localhost:5173`
